# -Simulator-
 Тривога! (Simulator) — інтерактивний симулятор системи сповіщень від J-Corp. Містить карту на базі Leaflet, шість категорій демонстраційних подій, журнал подій і налаштування кольорів інтерфейсу. Версія BETA 0.1. Проєкт створений для симуляції та тестування, а не для отримання реальних сповіщень.
